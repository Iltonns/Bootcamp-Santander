# 📊 Dashboard de Vendas XBOX

## 📋 Sobre o Projeto

Este projeto apresenta um **Dashboard interativo de Vendas XBOX** desenvolvido em Microsoft Excel, criado para análise e visualização de dados de vendas de produtos Xbox. O dashboard fornece insights valiosos sobre o desempenho de vendas, permitindo a tomada de decisões baseada em dados.

## 🎯 Objetivos

- Visualizar o desempenho de vendas de produtos Xbox
- Identificar tendências e padrões de vendas
- Analisar métricas-chave de desempenho (KPIs)
- Facilitar a tomada de decisões estratégicas através de visualizações intuitivas

## 📊 Dados Utilizados

O dashboard utiliza dados de vendas que incluem:

- **Informações de produtos**: Categorias, modelos e especificações de produtos Xbox
- **Dados de vendas**: Volume de vendas, receita, período de análise
- **Métricas de desempenho**: Indicadores-chave de desempenho (KPIs)
- **Análise temporal**: Dados distribuídos ao longo do tempo para identificação de tendências

> **Nota**: Os dados estão contidos no arquivo `Dashboard de Vendas XBOX.xlsx`

## 🛠️ Ferramentas Utilizadas

- **Microsoft Excel** - Desenvolvimento do dashboard e análise de dados
- **Recursos do Excel utilizados**:
  - Tabelas dinâmicas
  - Gráficos interativos
  - Segmentações de dados (Slicers)
  - Fórmulas avançadas
  - Formatação condicional

## 🚀 Como Reproduzir o Projeto

### Pré-requisitos

- Microsoft Excel 2016 ou superior (recomendado Excel 365)
- Sistema operacional: Windows, macOS ou acesso ao Excel Online

### Passos para Utilização

1. **Clone o repositório**
   ```bash
   git clone https://github.com/[seu-usuario]/Projetos-e-Desafios-Bootcamp-Santander.git
   ```

2. **Navegue até a pasta do projeto**
   ```bash
   cd "Projetos-e-Desafios-Bootcamp-Santander/Ciência de dados/Análise de dados com excel"
   ```

3. **Abra o arquivo Excel**
   - Localize e abra o arquivo `Dashboard de Vendas XBOX.xlsx`
   - Habilite edição e macros, se solicitado

4. **Explore o Dashboard**
   - Utilize os filtros e segmentações disponíveis
   - Interaja com os gráficos para visualizar diferentes perspectivas dos dados
   - Analise as métricas e KPIs apresentados

### Dicas de Uso

- 🔄 Utilize os **slicers** (segmentações) para filtrar dados por período, categoria ou produto
- 📈 Analise as **tendências** ao longo do tempo nos gráficos de linha
- 💡 Observe os **KPIs** destacados para métricas principais
- 🎯 Explore diferentes **visualizações** disponíveis nas abas do dashboard

## 📈 Funcionalidades do Dashboard

- ✅ Visualização de vendas totais por período
- ✅ Análise de performance por categoria de produto
- ✅ Comparação de resultados entre períodos
- ✅ Identificação de produtos mais vendidos
- ✅ Indicadores-chave de desempenho (KPIs)
- ✅ Filtros interativos para análise personalizada
